# OpenNox HD 0.1.0 preview

Windows 10/11 installer for the Hybrid 2x client. Requires an installed copy of Nox.

Download `opennox-hd-0.1.0-preview.1-windows-x86.zip`, extract all files, and run
`INSTALL.cmd`. Select your Nox folder and a separate installation destination.
Launch from the desktop shortcut. No developer tools or administrator rights needed.

- Per-file integrity checks, isolated installation, and original-sprite comparison.
- Fresh settings work on first launch; widescreen presets update both settings stores.
- The optional full overlay contains 124,244 2x sprites and HD fonts.
- Source snapshot and SHA-256 checksums accompany the package.

This is a local preview candidate. Interactive renderer acceptance, a verified
source rebuild, public signing, dependency-notice completion, and game-derived
artwork redistribution review are outstanding. It is not yet a public download.
No unmeasured performance improvement or complete visual acceptance is claimed.
